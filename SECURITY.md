# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open the repository's **Security** tab and choose
**Report a vulnerability**. Never report a vulnerability in a public issue, discussion or pull
request.

If the **Report a vulnerability** button isn't available, open a public issue that asks only for a
private contact channel. Don't include any details of the vulnerability in it.

Please include what you can of:

- the affected version or commit
- steps to reproduce, or a proof of concept
- the impact you expect

## Response

You'll get an acknowledgment within 3 business days. We'll keep you updated as we investigate and
fix the issue.

## Supported versions

No version has been released yet. Once releases exist, the latest release gets security fixes.

## Scope

- HiveMind's code in this repository
- its build and release pipeline, including the GitHub Actions workflows and code signing

Vulnerabilities in third-party dependencies or in Windows itself belong with their maintainers.
Tell us too if HiveMind is affected, and we'll update or work around the dependency.
